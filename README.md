# bircher988/tap

Homebrew formulae for tools that build software for the classic 68k Macintosh.

| Formula | What it is |
|---|---|
| [mac68k-asm](https://github.com/bircher988/mac68k-asm) | 68000 assembler, linker and resource compiler: builds Mac 128K/512K/Plus applications |
| [mac68k-disk](https://github.com/bircher988/mac68k-disk) | creates and edits MFS (400K) and HFS (800K) floppy disk images |

```
brew install bircher988/tap/mac68k-asm bircher988/tap/mac68k-disk
```

or `brew tap bircher988/tap` once, then `brew install mac68k-asm mac68k-disk`.
Both build from source; nothing but the Xcode command line tools is needed.
